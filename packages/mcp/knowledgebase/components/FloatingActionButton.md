# FloatingActionButton

## Component Name

FloatingActionButton

## Description

A floating action button that hovers over content, typically used for primary actions like adding items or creating new content.

## Important Constraints

- Use `FloatingActionButtonPlacement` to control placement
- Should have a clear, primary action
