# AppBar

## Component Name

AppBar

## Description

An app bar component for navigation at the top of a page or screen. Supports leading content, actions, and branding.

## Important Constraints

- Use `AppBarLeading` for leading content (e.g., back button, title)
- Use `AppBarActions` for action buttons on the right side
- Always provide an `AppBarContext` via `useAppBarContext` for nested components
