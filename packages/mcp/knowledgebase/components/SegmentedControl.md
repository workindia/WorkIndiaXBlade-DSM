# SegmentedControl

## Component Name

SegmentedControl

## Description

A segmented control component for switching between multiple options. Similar to a tab group but displayed as horizontal segments.

## Important Constraints

- Use `SegmentedControlItem` for each option
- Only one option can be selected at a time
